# Robots & Numbers (Unity 6)

A small WebGL Unity game i made with my friend for GMTK 2026

[Play](https://fraizumi.itch.io/robotsandnumbers)

## Concept

Use numbers to create ones that matches robot's request.

## What is used in project

- VContainer
- UniTask (for async tasks, like timer logic and its cancellation)
- PrimeTween (UI, robot conveyor movement)
